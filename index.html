Guide

I only have the 3D drawing, no physical part yet

Open the STEP/STL file in FreeCAD (free) or Blender (free). Rotate to the iso/front/side/top view you care about and export a screenshot or render as a PNG.

Upload those renders here the same way as a camera photo, labeled with the correct part number and view. They work as reference images the same as real photos — CLIP matching compares overall shape and features, not photo vs. render pixel-for-pixel.

How many reference photos do I need per part?

3–6 photos per part number, covering the angles a person is likely to photograph it from, works well. Add at least one "wrong orientation" example if that's a common real mistake on the line.

Backing up to OneDrive

Use Export library to download a single .json file containing all reference images and their fingerprints. Save that file into your OneDrive folder. On another phone/PC, open this same page and use Import library to load it back — no re-training needed.

Why can't this check exact dimensions?

A single photo has no reliable real-world scale or depth without a calibrated camera or a reference object in frame. This tool catches wrong parts, wrong orientation, and grossly wrong shapes — not sub-millimeter tolerance. For that, use calipers, a CMM, or a depth-camera 3D scan compared against the CAD model.
