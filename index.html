Guide

I only have the 3D drawing, no physical part yet

Open the STEP/STL file in FreeCAD (free) or Blender (free). Rotate to the iso/front/side/top view you care about and export a screenshot or render as a PNG.

Upload those renders here the same way as a camera photo, labeled with the correct part number and view. They work as reference images the same as real photos — CLIP matching compares overall shape and features, not photo vs. render pixel-for-pixel.

Why did I see an impossible confidence like 6913%?

That was a bug in an earlier version — the vision model's built-in normalization option wasn't reliably applying, which could produce oversized, inconsistent numbers instead of a true 0–100% confidence. It's fixed now: the app normalizes every photo's fingerprint itself before comparing.

Important: any reference photos saved before this fix have old, incorrectly-scaled fingerprints and will give wrong results when compared against newly scanned photos. Use Clear all reference photos below, then re-add them — this recomputes everything correctly. Drawings you attached are unaffected and don't need re-uploading.

Handling multiple revisions of the same part

When attaching a drawing, fill in the Revision field (e.g. REV0, REV1). You can attach several revisions for the same part number. If a scan matches a part with more than one revision on file, the technician sees a dropdown to pick which one to open — nothing opens automatically without their choice in that case.

Important: drawing sheets vs. reference photos

The Attach drawing section is for the file the technician reads (a dimensioned drawing sheet, PDF, or STL) — it's only for display, never used for camera matching.

Camera identification only works against the photos in Add reference photo above. A dimensioned drawing sheet full of lines and text won't match well against a real photo. If your drawing includes a small 3D/isometric picture of the part (many title-block drawings do), crop just that image and add it as a reference photo — or better, use real photos of the physical part for reliable matching.

Setting up automatic sync so nobody has to import manually

Build up your reference photos and drawings on one device (this is your "admin" device). When ready, tap Export shared library (.json) above — this downloads one file containing everything.

In your GitHub repo, create a folder called data the first time: click Add file → Create new file, type data/library.json as the filename, paste in any placeholder text, and commit. This creates the folder.

From then on, to publish updates: open the data folder in your repo, click into library.json, click the pencil (edit) icon, delete the old content, paste in the newly exported file's content, and commit.

That's it — every phone that opens your GitHub Pages link will automatically fetch this file in the background and load all the references and drawings. Nobody scanning parts needs to download or import anything themselves. If someone already has the app open, they can tap Refresh from GitHub now to pull the latest without reopening the page.

Auto-opening the drawing when a part is recognized

Use "Attach drawing to a part" to upload the actual drawing file per part number (separate from the training photos above). Images and PDFs preview automatically; STL files render as a rotatable 3D model. When the Scan tab recognizes that part with reasonable confidence, this drawing appears automatically under the result — no extra tap needed.

Raw STEP/STP files can't be previewed in a browser without conversion — for those, the app shows a download link instead of an inline view. If you want an automatic in-app preview, export a PDF or PNG of the drawing from your CAD software and attach that instead (or attach an STL for an interactive 3D view).

How many reference photos do I need per part?

3–6 photos per part number, covering the angles a person is likely to photograph it from, works well. Add at least one "wrong orientation" example if that's a common real mistake on the line.

Backing up to OneDrive

Use Export library to download a single .json file containing all reference images and their fingerprints. Save that file into your OneDrive folder. On another phone/PC, open this same page and use Import library to load it back — no re-training needed.

Why can't this check exact dimensions?

A single photo has no reliable real-world scale or depth without a calibrated camera or a reference object in frame. This tool catches wrong parts, wrong orientation, and grossly wrong shapes — not sub-millimeter tolerance. For that, use calipers, a CMM, or a depth-camera 3D scan compared against the CAD model.
